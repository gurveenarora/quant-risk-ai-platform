[1] Historical VaR (Non-Parametric): VaR_Hist(c, N-day) = -P_{1-c}(R_p) × √N

Calculates empirical quantile directly from past return distribution with zero Gaussian shape assumptions.

[2] Parametric VaR (Variance-Covariance): VaR_Param(c, N-day) = -(μ + z_{1-c} × σ) × Portfolio Value × √N

Assumes normal distribution using sample mean μ, standard deviation σ, and PPF Z-score z_{1-c}.
